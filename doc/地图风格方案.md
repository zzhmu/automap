# 地图风格（tileset）方案

> 2026-09-17 实现。目标：生成地图时可选「某个风格或某些风格」，风格决定
> **地面纹理 / 悬崖贴图 / 树木模型 / 野怪种类 / 雇佣兵营地外观**。

## 1. WE 格式约束（为什么"多选"是生成时随机抽一）

- w3e 头部只有一个 tileset 字母，全部地面纹理索引（0~15）引用该风格的纹理表
  → **一张图只能一种风格**；GUI 多选 = 每次生成随机抽一种。
- 同一种子多选时抽中的风格固定（`random.Random(seed).choice`），
  四个子步骤（地形/树/建筑/野怪）用同一个种子抽，不会各换各的。

## 2. 数据源：tools/tilesets.py（全项目唯一风格表）

8 个风格，全部数据经三处实证：

| 风格 | 字母 | 树 | 佣兵营地 | 纹理数 | 野怪池 |
|---|---|---|---|---|---|
| 洛丹伦的夏天 | L | LTlt | nmer | 6 | 25 种 |
| 洛丹伦的冬天 | W | WTtw | nmr3 | 6 | 27 种 |
| 洛丹伦的秋天 | F | FTtw | nmer | 6 | 17 种 |
| 灰谷 | A | ATtr | nmr5 | 8 | 29 种 |
| 荒地 | B | BTtw | nmr4 | 8 | 27 种 |
| 费尔伍德 | C | CTtr | nmr6 | 8 | 26 种 |
| 诺森德 | N | WTst | nmr7 | 7 | 18 种 |
| 城市 | Y | LTlt | nmr8 | 9 | 14 种 |

- **纹理表**：游戏 `TerrainArt/Terrain.slk` 按行序 = w3e 索引序
  （Ldrt/Ldro/Ldrg/Lrok/Lgrs/Lgrd = 0~5 实证）。
- **悬崖**：`CliffTypes.slk` 的 groundTile 列归属风格。
- **野怪池**：UnitData.slk **没有** tilesets 字段 → 只能从 45 张官方 1.27a
  对战图统计（`tools/_tmp/tileset_map_stats.py` → style_map_stats.txt）。
- **CONVERT**：Terrain.slk convertTo 列的跨风格语义等价映射
  （如 Lgrs→{F:Fgrs, W:Wgrs, A:Agrs, N:Nsnw, ...}，4 个缺失项人工补到灰谷）。

## 3. 各层怎么接

| 层 | 文件 | 做法 |
|---|---|---|
| 地形 | gen_height.py `apply_style()` | 重写 w3e 头（tileset 字母+纹理/悬崖表，HS 变化→角点区整体重建）；角点纹理索引经 CONVERT 语义映射、悬崖索引 clamp。flags/高度/层/variation 一概不动（换皮不换骨） |
| 地面涂刷 | gen_height.py `paint_textures()` | 见 §4 |
| 树 | add_doodads.py | `--tree-id <id>`；没显式给时 random_map 传 `STYLES[style]["tree"]`；FALLBACK_TREES 按风格修正（N=WTst 雪松、W=WTtw、C=CTtr、F=FTtw、Y=LTlt） |
| 建筑 | add_buildings.py | 雇佣兵营地 nmer → `STYLES[style]["merc"]`（nmr3~nmr8）；其余建筑不变 |
| 野怪 | add_creeps.py `filter_templates()` | 组合模板只留全部 id ∈ 风格池 ∪ {uDNR} 的；空池回退全局 |

## 4. 地面纹理涂刷（本次新补的关键一环）

**问题**：5 张模板 `.w3m` 全图纹理索引恒为 0（纯泥地，实测 {0: 全部角点}），
风格转换只是"泥地换泥地"，换完看不出风格纹理差异。

**做法**（`paint_textures`，在角点写回前重涂，L 语义索引 0~5）：

- 深水水底 = 深色泥地(1)，浅水水底 = 泥地(0)
- 层差线两侧一圈 = 岩石(3)（崖壁脚下/台地沿口；同层水陆边界不算）
- 斜坡走道 = 泥地(0)
- 陆地按大团块噪声（~22 格 + 6 格碎斑扰动阈值）分：
  暗草团块(5, b<0.30) / 草地(4, 默认) / 粗泥过渡环(2, 0.66~0.74) / 泥地斑块(0, b>0.74)
- 单层模式（无悬崖）陆地最高 1.5% 点缀岩石

**关键技巧**：涂刷只写模板（L）语义的索引 0~5，`apply_style` 的 CONVERT
映射自动把它变成目标风格等价纹理（Lgrs→Agrs/Wgrs/Nsnw…），
**不需要每个风格一张涂刷表**。

实测输出（64 图，seed 777）：

| 输出 | 纹理分布（角点占比） |
|---|---|
| L | Lgrs 25% / Lgrd 29% / Ldrt 25% / Ldro 12% / Lrok 3% |
| A | Agrs 25% / Agrd 29% / Adrt 25% / Adrd 12% / Arck 3% |
| W | Wgrs 25% / **Wsnw 29%** / Wdrt 25% / Wdro 12% |
| N | **Nice 29% / Nsnw 25%** / Ndrt 25% / Ndrd 12% / Nrck 3% |

## 5. GUI / CLI 入口

- CLI：`--style A` / `--style A,W,N`（多选随机抽一）；不给 = 跟随模板（L）。
- GUI：「地图风格（TILESET）」面板，8 个复选框（L 默认勾选），
  `/api/state` 下发 `styles` 列表，结果徽章显示「风格 灰谷」。
- 生成日志：`地图风格: 灰谷（A）` + `地面纹理涂刷: 泥地 26% / ...`。

## 7. 已知边界

- 模板全是 tileset L → `--style L` 时 apply_style 不触发（纹理涂刷照常生效）。
- uDNR（随机占位野怪）不属于任何风格池，过滤时始终放行。
- Y（城市）纹理表 9 张、含 Ysqd/Yrtl 等特殊贴图，涂刷只用了语义等价的 6 张，
  剩余 3 张保持模板默认分布（不影响正确性）。

## 🔴 追加：w3e 头部 offset 字段（2026-09-17 修复）
w3e 头 width/height 之后还有 8 字节 = **地形原点的世界坐标偏移（两个 float32）**，
标准值 `(-W*64, -H*64)`（模板 5 张、官方图、WE 自存图全部如此）。
游戏按 `世界坐标 = offset + 索引*128` 渲染地形，而树/建筑/野怪直接用世界坐标。
`apply_style` 重建头部时曾把这两字节写成 (0,0) ⇒ 非 L 风格地图**地形整体向右上
平移半张图，物件看起来向左下偏移半图**（L 风格走原地改字节路径，不受影响）。
已修复：`read_header` 捕获 `info["offset"]` 原始 8 字节，`apply_style` 回写。

## 🔴 追加：悬崖贴图跟随地面语义（2026-09-17 晚）
用户报告「悬崖是泥土、周围是草」。两个叠加 bug：
1. `gen_height` 悬崖索引全图恒 1——L 下恰好是草崖没露馅，A 下索引 1 = CAdi（泥崖），
   配草地就撞色；
2. `apply_style` 原按序号直搬悬崖索引——各风格表顺序不同（L=[CLdi泥,CLgr草]，
   A=[CAgr草,CAdi泥]），语义会错位。

修复：
- `paint_cliffs(painted, is_water)`：逐角点按涂刷地面语义选崖（泥系 0-2→泥崖，
  草/岩 3-5→草崖，水→泥崖）；
- `apply_style`：**逐角点按「新地面纹理」选崖**（cliff_for_tex 预解析）——精确匹配
  `CLIFF_GROUND == 新地面id`（Wsnw→CWsn），无则按 L 语义族回退，最后表首。
  静态映射不够：W 冬天表只有 [CWgr草,CWsn雪] 无泥崖，L 的 CLdi 匹配失败会全部
  回退到索引 0，雪崖 CWsn 就永远用不上（实测修复后雪崖 24.4%）。

数据源：`TerrainArt\CliffTypes.slk`（游戏 MPQ，mpyq 读）——16 个悬崖 id 的
`groundTile` 列，落在 `tilesets.CLIFF_GROUND`。

实测（128 图 seed 4242）：L / A / N 崖角点语义一致 **100%**；W 82.4%，剩余不一致
全部是「泥地面想配泥崖但冬天表里没有泥崖」的受迫选择（数据约束，非 bug）。
GUI 端到端诺森德图：offset ✓ / 两表 ✓ / 崖角点一致 1066/0 / inspect_units 全 0。

## 🔴 追加：崖面一致化（2026-09-17 下午）
用户游戏内反馈崖壁出现「半草半泥」花斑。官方 12 张图扫描结论：
**16058 条崖面的两端贴图混合率为 0.0%**——官方策略是整面崖壁一种贴图
（崖贴图语义仅 69%/66% 跟随高/低地侧地面，统一优先于语义）。
逐角点选崖导致崖面混合 3.8%，而 WC3 崖壁按角点插值渲染，两端贴图不同
即花斑。修复：`_unify_cliff_faces` 崖环多数票（组件=有层差 4 邻的角点，
8 邻连通，不要把崖脚圈并进组件以免粘连相邻台地）。修复后四风格混合率 0%。
apply_style 同样在逐角点选崖后加环投票覆写。
